# mruby public C API: structs and fields

Source: /home/user/mruby at commit 8c7d5f35b. Headers read: include/mruby.h and include/mruby/*.h, without include/mruby/internal.h and include/mruby/presym/.
The .c files were read only to learn what the code does with a field.

How to read the table:

- "header" fields come from MRB_OBJECT_HEADER (object.h:10-15). Every object struct starts with them. They are listed once under RBasic. Each other struct has a "flags" row only where it gives the bits its own meaning, and a "c" row where c means something special.
- "never from outside mruby" means that only code inside the core writes the field. A write from an extension breaks a rule that the core code keeps, and the cell names that code.
- A write of a pointer to a heap object into a field that the GC marks needs mrb_field_write_barrier (gc.c:1971-1990). A plain C assignment does not do it.
- The GC does not move objects. A pointer to an object or into it stays valid until the GC frees the object, or until the object replaces the buffer the pointer points into.

## What changes with the boxing and with configuration

- mrb_value has a different definition for each boxing: one uintptr_t w in word boxing (boxing_word.h:194-196), one uint64_t u in nan boxing (boxing_nan.h:40-42), and a union plus a type tag in no boxing (boxing_no.h:198-210). Word boxing is the default; value.h:267-273 picks the header.
- RFloat exists only in word boxing (boxing_word.h:69-103). Its field f is a char array where floats are not inline (MRB_WORDBOX_NO_INLINE_FLOAT, boxing_word.h:64-67, 72-77).
- RInteger exists in word boxing (boxing_word.h:105-108) and nan boxing (boxing_nan.h:82-85), not in no boxing. In nan boxing the core makes one only with MRB_INT64 (etc.c:482-505).
- RCptr exists only in word boxing, or in nan boxing on a 64-bit build (value.h:260-265).
- RArray: the embedded form as.ary is absent with MRB_ARY_NO_EMBED, which array.h:29-35 sets by itself on 32-bit nan boxing and on 32-bit no boxing with 8-byte members. MRB_ARY_EMBED_LEN_MAX depends on sizeof(mrb_value) (array.h:40).
- RRange holds beg and end inside the object with word boxing or 64-bit nan boxing (MRB_RANGE_EMBED, range.h:17-27); otherwise it holds a pointer to a separate mrb_range_edges (range.h:31-44).
- RBreak holds val as an mrb_value on 64-bit and with word boxing; on other builds it holds the bits in a uint32_t array, and in no boxing the type tag goes into flags bits 0-7 (error.h:47-106).
- RHash has a different field order and different fields on 64-bit and 32-bit (hash.h:18-33). On 32-bit the entry-array capacity and use count live in flags or in the hash table (hash.c:146-157).
- RString: RSTRING_EMBED_LEN_MAX depends on the pointer size (string.h:19-20). The coderange bits are written only with MRB_UTF8_STRING (string.h:129-149).
- RProc flags bits 0-6 and 16-19 hold a refinement scope index with MRB_USE_REFINEMENTS (proc.h:178-190).
- mrb_state: float_class needs floats (mruby.h:398-400); nan_serial exists only without word boxing and with floats (mruby.h:433-440); the refinement fields need MRB_USE_REFINEMENTS (mruby.h:414-429); cache, iv_cache and const_cache depend on MRB_NO_METHOD_CACHE, MRB_NO_IV_CACHE and MRB_NO_CONST_CACHE (mruby.h:453-463); symbuf is absent with MRB_USE_ALL_SYMBOLS (mruby.h:472-474); the debug hooks, bytecode_decoder, arena_err, atexit_stack and task fields depend on their switches (mruby.h:476-503, 531-533).
- mrb_gc: arena is a fixed array with MRB_GC_FIXED_ARENA, else a heap pointer with arena_capa (gc.h:83-88).
- struct mrb_jmpbuf: impl is jmp_buf, or void* with MRB_USE_CXX_EXCEPTION (throw.h:38-79).
